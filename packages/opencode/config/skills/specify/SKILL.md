# Specify

Before acting, inspect applicable `AGENTS.md`, `README*`, `CONTRIBUTING*`, `Justfile`, `Makefile`, `flake.nix`, `package.json`, `pyproject.toml`, `Cargo.toml`, `CMakeLists.txt`, CI workflow files, existing tests, and Git metadata for the default branch. Treat absent conventions as unknown and do not guess destructive operations.

Do not edit code or save the result automatically. Treat documentation as authoritative only when the repository establishes it as such.

Separate required behavior from implementation ideas. Do not silently decide unknown requirements. Record small uncertainties as explicit assumptions; ask the user about consequential design branches. Stop when acceptance criteria are testable and material decisions are either resolved or listed as open.
